Claude Code Manager — 安装说明（Kali / Debian）
================================================

这是一个图形化管理工具，用来一键安装和管理 Claude Code。

本说明只讲怎么把这个程序装上。装完之后怎么用，见「装完之后」一节。

本说明配套版本：1.3.7


──────────────────────────────────────────────
压缩包里有什么
──────────────────────────────────────────────

    claude-code-manager_1.3.7_amd64.deb     要装的就是这个
    安装说明.txt                            本文件
    校验值.txt                              安装包的指纹（可选）
    screenshots/                            界面截图，可忽略


──────────────────────────────────────────────
第一步：解压
──────────────────────────────────────────────

在文件管理器里右键 CCM-Kali-1.3.7.zip →「解压到此处 / Extract Here」，
得到 CCM-Kali-1.3.7 文件夹。

（可选）先确认压缩包没在传输中损坏：把 CCM-Kali-1.3.7.zip 和
CCM-Kali-1.3.7.SHA256SUMS.txt 放同一个文件夹，在那里开个终端执行

    sha256sum -c CCM-Kali-*.SHA256SUMS.txt

末尾显示 OK 就是好的；显示 FAILED 说明文件在传输中坏了，请让发你的人重传。


──────────────────────────────────────────────
第二步：在文件夹里打开终端
──────────────────────────────────────────────

先**双击进入解压出来的那个 CCM-Kali-… 文件夹**（不是外面只有 zip 的那一层），

    在文件夹的空白处点右键 →「在这里打开终端 / Open Terminal Here」

右键菜单里如果没有这一项，用这个办法：按 Ctrl+L 让地址栏可编辑，
把里面的路径整段删掉，只留一个词，回车：

    terminal

确认位置对不对 —— 应该能列出安装包：

    ls claude-code-manager_1.3.7_amd64.deb

列出来了就说明位置没错，继续下一步。


──────────────────────────────────────────────
第三步：安装
──────────────────────────────────────────────

就这一行（文件名很长，敲到 claude 按一下 Tab 键会自动补全）：

    sudo apt install ./claude-code-manager_1.3.7_amd64.deb

第一次用 sudo 会要密码：输入时屏幕上什么都不显示，这是正常的，
照常输完回车即可。等命令跑完，装好了。

三个要点，缺一个就会失败：

  1. ./ 不能省略
     写成不带 ./ 的形式，apt 会去软件源里找，然后报「无法定位软件包」。

  2. 必须有 sudo
     安装要写入 /opt 和 /usr/share/applications。

  3. 用 apt，不要用 dpkg -i
     apt 会自动把缺少的依赖一起装上；dpkg -i 不会，依赖缺失时包会卡在
     「未配置」状态。已经用 dpkg -i 装出问题了，执行：

         sudo apt install -f


──────────────────────────────────────────────
装完之后
──────────────────────────────────────────────

程序会自动创建桌面图标（中文系统的桌面是 ~/桌面，英文系统是 ~/Desktop；
两个目录都存在时，两个里面都会放一份）。

启动方式任选一种：

    · 双击桌面上的 "Claude Code Manager" 图标
    · 应用菜单里搜索 "Claude Code Manager"
    · 终端里输入 claude-code-manager

注意命令是 claude-code-manager，**不是 ccm** —— ccm 是另一个独立的终端
工具，和本程序无关。

打开程序后：

    · 首次启动会自动浮出一个向导，带你过一遍主要功能，可以随时跳过。
    · 想再看一遍：左侧「通用设置」→「重新打开向导」。
    · 装 Claude Code 本身、配 API Key、设置模型层级，都在左侧各个面板里，
      首次启动的向导会告诉你每一项在哪。


──────────────────────────────────────────────
安装出问题时
──────────────────────────────────────────────

【提示 "无法定位软件包" / "Unable to locate package"】

    少了 ./

    正确：sudo apt install ./claude-code-manager_1.3.7_amd64.deb
    错误：sudo apt install claude-code-manager_1.3.7_amd64.deb

【提示 "Permission denied" / "权限不够"】

    少了 sudo，或者你在双击运行这个 deb 文件。
    deb 是安装包，要用 apt install 安装，不能直接运行。

【提示依赖问题】

    sudo apt install -f

【装好了但找不到程序】

    在终端里直接运行，看有没有报错：

        claude-code-manager

【其他任何问题】

    把下面三行命令的完整输出发回来：

        cat /etc/os-release | head -3
        dpkg -l claude-code-manager
        claude-code-manager


──────────────────────────────────────────────
卸载
──────────────────────────────────────────────

    sudo apt remove claude-code-manager

想连配置一起清掉：

    rm -rf ~/.local/share/claude-code-manager

然后编辑 ~/.bashrc、~/.zshrc、~/.profile，删掉这两行之间的内容：

    # >>> claude-code-manager >>>
    ...
    # <<< claude-code-manager <<<
